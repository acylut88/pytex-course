## 🌐 Что такое API?

> **API** (*Application Programming Interface* / Программный интерфейс приложения) — это набор общедоступных «ручек» (эндпоинтов) или рычагов приложения, которые позволяют внешним клиентам (браузеру, мобильному приложению или стороннему разработчику) взаимодействовать с серверной частью.

### 🍽 Аналогия из реальной жизни: Ресторан
Представь, что ты пришёл в ресторан:
1. **Ты (Клиент)** просишь принести коктейль и закуски.
2. **Официант (API)** принимает твой заказ и передаёт его на кухню.
3. **Кухня и повара (Бэкенд / База данных)** готовят блюда, смешивают ингредиенты и обрабатывают запрос.
4. **Официант (API)** возвращает тебе готовый заказ.

**Почему Официант — это API?** 
Тебе как клиенту не нужно знать поваров лично, учить их профессиональный жаргон, понимать, в каких пропорциях бармен смешивает напитки или на каком языке они говорят на кухне. Официант берёт всю эту сложную внутреннюю коммуникацию на себя и предоставляет тебе **простой и понятный интерфейс** для работы с кухней.

В мире веб-разработки:
* **Языки, на которых говорят повара** — это языки программирования (Python, Go и др.).
* **Приготовление блюд** — это обращение к базе данных и обработка информации.
* **Адрес эндпоинта** (например, `://site.com`) — это конкретная «ручка» API, за которую можно дернуть и получить список отелей.

## ⚡ Что такое FastAPI?

> **FastAPI** — это современный, быстрый (высокопроизводительный) фреймворк (с технической точки зрения — библиотека) на языке Python, предназначенный для создания API.

FastAPI был выпущен относительно недавно — в **2018 году**. Его написал и продолжает развивать один человек — Себастьян Рамирес (*tiangolo*). На сегодняшний день FastAPI занимает **3-е место по популярности** среди Python бэкенд-фреймворков, уступая только Django и Flask. Однако на рынке бэкенд-разработки наблюдается устойчивый тренд перехода на FastAPI, и вакансий с его требованием становится всё больше.

### 🔥 Главные фишки фреймворка:
* **Встроенная асинхронность:** из коробки поддерживает асинхронное программирование (`async/await`).
* **Автоматическая документация:** генерирует интерактивную документацию к вашему API в форматах **OpenAPI** и **Swagger**.
* **Валидация данных:** встроенная строгая проверка типов через популярную библиотеку **Pydantic**.
* **Простота и скорость:** высокая скорость как написания кода, так и работы самого приложения.
* **WebSockets:** удобная и простая работа с веб-сокетами по сравнению с тяжеловесным Django Channels.

📌 *Официальная документация фреймворка:* [://tiangolo.com](https://://tiangolo.com/)

## 🛠 Подготовка окружения и установка

Современная бэкенд-разработка немыслима без изоляции зависимостей под каждый конкретный проект. Рекомендуется использовать встроенный инструмент `virtualenv` или продвинутый менеджер зависимостей `Poetry`. Для курса подойдет любая современная версия Python: `3.10`, `3.11` или `3.12`.

### ⚠ Важное замечание по установке:
Вместо базовой команды `pip install fastapi` **используй расширенную установку**:

```bash
pip install "fastapi[standard]"
```
*Флаг `[standard]` (кавычки могут отличаться в зависимости от терминала) автоматически установит полный набор библиотек и сервер, необходимых для полноценной работы.*

### 🛑 Нюанс для пользователей Windows:
Если ты устанавливаешь зависимости через готовый файл `requirements.txt` из репозитория курса, **обязательно удали оттуда библиотеку `uvloop`**. 
* `uvloop` — это быстрая замена классического событийного цикла (Event Loop) в Python.
* Она **не поддерживается на Windows**. Вернуть её в проект нужно будет только тогда, когда ты будешь разворачивать проект на реальном сервере под управлением Linux.

## 🚀 3 способа запуска FastAPI

Для того чтобы обрабатывать запросы пользователей в бэкенд-среде, нам необходим асинхронный веб-сервер. В экосистеме FastAPI эту роль выполняет сервер **Uvicorn**. Он принимает HTTP-запросы из сети и перенаправляет их в наше приложение FastAPI, а затем возвращает ответы клиенту.

### Способ 1: Самый простой (Команда `fastapi dev`)
Отлично подходит для тех, кто только начинает свой путь в бэкенде:

```bash
fastapi dev main.py
```

### Способ 2: Классический через CLI (Команда `uvicorn`)
Этот способ доминировал последние несколько лет во всех видеоуроках и статьях:

```bash
uvicorn main:app --reload
```
* Здесь `main` — это имя твоего Python-файла (`main.py`), а `app` — название переменной, в которой создан объект `FastAPI()`.
* Флаг `--reload` автоматически перезапускает сервер при изменении кода.

### Способ 3: Профессиональный (Через конструкцию `__main__`)
Именно этот способ чаще всего применяется в **production-коде** (на реальных серверах). Он позволяет лаконично запускать проект обычной командой, а все настройки конфигурации хранить прямо внутри кода.

Внутри файла `main.py` прописывается следующий блок:
```python
import uvicorn
from fastapi import FastAPI

app = FastAPI()


# Твои эндпоинты (роуты) здесь...

if __name__ == "__main__":
    uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=True)
```

После этого запуск сервера выполняется стандартной командой Python:
```bash
python main.py
```

## 🌐 Проверка работы сервера

По умолчанию Uvicorn запускает приложение на порту `8000`.
1. Перейди в браузере по адресу: [http://localhost:8000/](http://localhost:8000/).
2. Если всё запущено верно, сервер вернёт JSON-ответ: `{"detail": "Not found"}` (так как мы ещё не создали главную страницу).
3. Для перехода к автоматической интерактивной документации твоего API зайди по адресу:
   * **Swagger UI:** [http://localhost:8000/docs](http://localhost:8000/docs)
   * **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)
