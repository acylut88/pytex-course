# 📚 Урок: Асинхронность в Python

## 💡 Что такое асинхронность?
**Асинхронность в Python** позволяет выполнять задачи одновременно, что значительно повышает производительность при работе с операциями ввода-вывода (**I/O-bound**). 

### Основные сферы применения:
* 🌐 Обращения к базам данных
* 📡 Сетевые API-запросы
* 💾 Чтение и запись тяжелых файлов

### 🔄 Синхронный vs Асинхронный подход
* **В синхронных программах** задачи выполняются строго последовательно. Каждая текущая задача полностью блокирует выполнение всех остальных до тех пор, пока сама не завершится.
* **Асинхронный подход**, напротив, позволяет программе эффективно «ожидать» завершения долгой задачи (например, ответа от сервера), продолжая в этот момент выполнять другие полезные вычисления.

---

## 🛠 Ключевые инструменты asyncio

### 1. Концепция `async` / `await`
Ключевые слова `async` и `await` используются для объявления и управления асинхронными функциями:
* Функция, объявленная с помощью модификатора **`async def`**, превращается в корутину (coroutine).
* Оператор **`await`** приостанавливает выполнение текущей функции до завершения ожидаемой задачи (например, сетевого запроса), не блокируя при этом основной поток всей программы.

### 2. Функция `asyncio.gather`
Удобный инструмент для параллельного выполнения нескольких асинхронных задач:
* Принимает на вход список корутин (асинхронных функций).
* Запускает их одновременно и возвращает единый список результатов выполнения всех этих функций.
* Позволяет выполнять пачку независимых задач, не дожидаясь завершения каждой по отдельности.

## 📝 Пример использования (Сравнение)

```python
import asyncio
import time

# ❌ Синхронная функция (Блокирующая)
def get_data_from_database(query: str):
    print(f"Получен запрос: {query}")
    if query == "Сочи":
        time.sleep(4)
    elif query == "Дубай":
        time.sleep(2)
    print(f"Данные получены: {query}")

#  Асинхронная функция (Неблокирующая)
async def get_data_from_database_async(query: str):
    print(f"Получен запрос: {query}")
    if query == "Сочи":
        await asyncio.sleep(4)
    elif query == "Дубай":
        await asyncio.sleep(2)
    print(f"Данные получены: {query}")
    return "Results"

# Пример асинхронного вызова с использованием asyncio.gather
async def main():
    tasks = [
        get_data_from_database_async("Сочи"),
        get_data_from_database_async("Дубай")
    ]
    # Запускаем обе задачи параллельно
    results = await asyncio.gather(*tasks)
    print("Все данные получены:", results)

# Запуск программы
if __name__ == "__main__":
    asyncio.run(main())
```

> **Итог примера:** Использование `asyncio.gather` позволяет запрашивать данные из базы одновременно для обоих городов, что значительно сокращает общее время выполнения программы по сравнению с последовательным синхронным подходом.

## 🎯 Практическое задание: «Собрать дашборд пользователя»

### Описание
**Дашборд пользователя** — это главный экран личного кабинета, где одновременно отображаются его личный профиль, история бронирований, популярные отели сети и персональные рекомендации.

### Ваша задача
Вам уже даны готовые асинхронные функции. Нужно **дописать только функцию `main()`**: 
1. Правильно расположить вызовы функций.
2. Учесть зависимости между ними (некоторые данные нельзя запросить, не получив ID пользователя или список его бронирований).
3. Использовать асинхронность там, где это возможно.
4. Вывести в консоль итоговый дашборд и общее время выполнения программы через `time.perf_counter()`.

> **Цель:** Собрать итоговый дашборд и сделать это быстрее, чем при полностью последовательном выполнении. **Менять готовые функции нельзя!**

### ⏳ Целевые метрики времени выполнения:
* При базовом использовании `gather` можно получить минимально **5.2 секунды**.
* Если использовать асинхронность на максимум (с помощью `asyncio.create_task`), можно добиться выполнения всего за **4.2 секунды**!

### Исходный шаблон кода для задания:

```python
import asyncio
import time

async def login():
    print("Авторизуем пользователя...")
    await asyncio.sleep(1)
    print("Пользователь авторизован")
    return 42

async def get_user_profile(user_id):
    print(f"Получаем профиль пользователя {user_id}...")
    await asyncio.sleep(1)
    print("Профиль получен")
    return {"user_id": user_id, "name": "Алексей"}

async def get_user_bookings(user_id):
    print(f"Получаем бронирования пользователя {user_id}...")
    await asyncio.sleep(2)
    print("Бронирования получены")
    return [
        {"hotel": "AZIMUT Сити Отель Смоленская", "city": "Москва"},
        {"hotel": "Cosmos Saint-Petersburg Nevsky Hotel", "city": "Санкт-Петербург"}
    ]

async def get_popular_hotels():
    print("Получаем список популярных отелей...")
    await asyncio.sleep(3)
    print("Популярные отели получены")
    return [
        {"hotel": "Marins Park Hotel", "city": "Сочи"},
        {"hotel": "AZIMUT Отель", "city": "Казань"},
        {"hotel": "Cosmos Selection", "city": "Москва"}
    ]

async def get_recommendations(bookings):
    print("Получаем персональные рекомендации...")
    await asyncio.sleep(1)
    print("Рекомендации получены")
    return [
        {"hotel": "Гранд Отель Жемчужина", "city": "Сочи"},
        {"hotel": "AZIMUT Парк Отель", "city": "Переславль-Залесский"}
    ]

async def build_dashboard(profile, bookings, popular_hotels, recommendations):
    print("Собираем дашборд...")
    await asyncio.sleep(0.2)
    return {
        "profile": profile,
        "bookings": bookings,
        "popular_hotels": popular_hotels,
        "recommendations": recommendations
    }

async def main():
    start_time = time.perf_counter()
    
    # 🛠 НАПИШИТЕ ЗДЕСЬ ВАШУ ЛОГИКУ ВЫЗОВА ФУНКЦИЙ
    
    print("Времени прошло:", time.perf_counter() - start_time)

if __name__ == "__main__":
    asyncio.run(main())
```
